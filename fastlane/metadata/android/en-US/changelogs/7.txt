This release brings experimental support for cross-platform authentication using CTAP 2.3's PXP over Bluetooth!

Enable it in Settings and use an appropriate camera app to open a QR code with Keyholm.

I've been personally using it with the latest release of https://github.com/linux-credentials/credentialsd and haven't run into any bugs yet.
I need your help, so please test it with any client you can!
